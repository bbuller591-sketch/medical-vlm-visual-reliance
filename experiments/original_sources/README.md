# Auditable original experiment code (research archive)

This directory preserves the **original implementation scripts** for the previous studies, as reference material. It includes stage-specific methods that are not all part of the simple portable CLI: representation features, hidden-state linear probes, TVI, activation patching, visual knockout, entropy/VES diagnostics, and the quality × relevance experimental infrastructure.

- [[`official900_visual_reliance_v1/scripts/common.py`](https://github.com/bbuller591-sketch/medical-vlm-visual-reliance/blob/main/experiments/original_sources/official900_visual_reliance_v1/scripts/common.py)](https://github.com/bbuller591-sketch/medical-vlm-visual-reliance/blob/main/experiments/original_sources/official900_visual_reliance_v1/scripts/common.py): original dataset loading, image degradation definitions, prompts, seed/permutation logic and metrics.
- [`visual_reliance_mechanism_v2/scripts/`](https://github.com/bbuller591-sketch/medical-vlm-visual-reliance/tree/main/experiments/original_sources/visual_reliance_mechanism_v2/scripts): original matched-processing mechanism scripts, including [`m6_probes.py`](https://github.com/bbuller591-sketch/medical-vlm-visual-reliance/blob/main/experiments/original_sources/visual_reliance_mechanism_v2/scripts/m6_probes.py), [`m8_patching.py`](https://github.com/bbuller591-sketch/medical-vlm-visual-reliance/blob/main/experiments/original_sources/visual_reliance_mechanism_v2/scripts/m8_patching.py), and [`m9_knockout.py`](https://github.com/bbuller591-sketch/medical-vlm-visual-reliance/blob/main/experiments/original_sources/visual_reliance_mechanism_v2/scripts/m9_knockout.py).

**These are archived raw source files, not an independently verified one-command package.** Their original workflows depend on experiment-specific input trees, donor maps, and cached feature shards, and are not all runnable without recreating that environment. They are included for method transparency and exact implementation reference, **not** as a claim that `README.md`'s lightweight quick start reproduces every mechanism result. The portable and GPU smoke-tested primary behavioral pipeline lives in `scripts/` at repository root.

Any absolute machine-specific source comments were neutralized for public release. No pretrained weights, patient images, experimental large feature tensors, private paths, or credentials are included.
